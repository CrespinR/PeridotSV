# Peridot.sv - Página web

## Cómo abrirla
1. Descarga/descomprime la carpeta.
2. Abre `index.html` con Google Chrome, Edge o Firefox.

## Archivos
- `index.html`: estructura de la página.
- `styles.css`: diseño responsive inspirado en el mockup.
- `script.js`: catálogo, ventanas "Más info", personalizador "Hazlo Tú", carrito y formulario de pedido.

## Nota
Es una versión demostrativa para el proyecto académico. No incluye backend, base de datos ni pagos reales.
